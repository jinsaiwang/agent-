CHAPTER 03

ZCode · 国产大模型编程 ADE

智谱 Z.ai编程 ADEGLM 深度适配学生友好 ★★★★
目标
知道 ZCode 是「Agentic 开发环境」、深度适配哪些模型，理解它为什么适合跑长程编程任务，并留意其数据安全争议。

ZCode 是智谱 Z.ai（原智谱 AI）推出的 Agentic 开发环境（ADE）——把 AI Agent 放在工作流中心：用自然语言描述目标，由它驱动「编码 → 调试 → 预览 → 迭代」全流程。最大亮点是深度适配国产 GLM 大模型（1M 长上下文），且应用本体可免费下载。新用户试用期为 5 天，客户端显示额度为 GLM-5.3 每日 300 万 Token、GLM-5.3-Flash 每日 500 万 Token；试用结束后，模型推理可能需连接套餐或自带 API Key。

核心能力（点击展开看详情）

①Agentic 开发环境定位+

不是给编辑器装个插件，而是独立的 ADE（Agentic Dev Environment）：AI Agent 位于工作流中心，用自然语言描述目标，由它驱动「编码 → 调试 → 预览 → 迭代」全流程，重在"把事办成"。

独立 IDE对标 Cursor
②Goal Mode 可验收目标核心+

把指令变成「可验收目标」状态机，每轮自动验证是否达成，没达成就继续。failed-closed 设计保证不会谎报"已完成"——这是它和只会聊天的工具有本质区别的地方。

防谎报
③Subagents 多智能体+

一个大目标可拆成多个 Agent 并行（如一个写 auth、一个写测试、一个查文档），适合复杂、互相独立又需协同的任务，速度显著快于单线程。

并行
④Remote Control 远程派单+

通过 微信 / 飞书（官方 Bot Channel）随时唤起派单，不在电脑前也能推进长任务——睡前丢一句需求，醒来看结果。手机是入口，不是鸡肋。

手机可派活
⑤GLM-5.2/5.3 + 1M 上下文+

深度适配国产 GLM-5.2 / 5.3，提供 1M tokens 长上下文：大型重构、多文件协调、依赖更新等长程任务优势明显，且国内直连、中文原生。

国产模型长上下文
⑥20+ 工具 & Checkpoint 审查+

内置 20+ 工具（文件、终端、Git、包管理、构建、测试、Lint、数据库、API 测试）；每步用 Checkpoint 暂停展示 diff，经审批后继续，支持 MCP 接入更多能力。改动量会实时累计（截图右上角的 Changes +15369 −0 即是），并且每次对话都能回溯后改写需求继续执行，不必从头重来。

可管控
⑦数据自主权须知+

2026-09 曾发生代码数据上传争议，官方已致歉、开源并整改，提供本地 / 私有化选项与分级权限。敏感 / 专有代码建议自托管 GLM 或留意隐私设置，密钥勿直贴。

敏感代码留意
性价比
应用本体免费下载，入门档月费在几款里偏低，还能自带 API Key 走按量。做项目、学编程的性价比最高；代价是模型生态较封闭，且敏感代码要考虑自托管。

上手三步走

  1. 1 下载 ZCode 桌面端（macOS / Windows / Linux 测试版），注册 Z.ai 账号
  2. 2 接模型：订阅 GLM Coding Plan，或自带 API Key 走按量（兼容 OpenAI / Anthropic 协议的服务均可接入）
  3. 3 用 /goal 设定可验收目标，让它规划→执行→验证；出门用微信/飞书远程派单
典型场景示例「给这个 Flask 项目加用户登录并补测试」：ZCode 用 Goal Mode 拆成「建 auth 模块 / 写测试 / 接数据库」并行推进，每步 Checkpoint 都能先审 diff 再放行，长上下文让它跨多文件不丢上下文。

优缺点对照

优势

  • 应用免费、国产模型、国内直连，学生门槛最低
  • 1M 长上下文 + Goal 可验收，长程任务强
  • GUI 单窗口 + 微信/飞书远程控制，比纯终端友好
  • GLM-5.2 权重 MIT 开源，可自托管保隐私（5.3 许可不同）

注意

  • 2026-09 曾发生代码数据上传争议，官方已致歉、开源并整改；敏感代码留意
  • 原生深度适配 GLM，其他模型通过兼容协议接入，体验不如 GLM 丝滑
  • 无移动/网页版（远程控制是手机入口）；Linux 仍测试版；生态较新
