怎么读这张表

先分类
先看使用方式，再分开比较能力。码道CodeArts官方定位是智能编码产品，同时覆盖全栈开发、代码质量管理、文档、设计和分析；本站因此分别列出“编程工程能力”和“通用任务能力”，避免用单一总分掩盖它的强项。WorkBuddy偏通用工作，TraeWork / ZCode / Codex偏编程工作流。
排除法
不想折腾代理、也不想付美元，Codex 可以先放一放——不是它不强，是默认路径获取成本太高。真想用也有办法：它读的是本地 config.toml，把 provider 指向 DeepSeek 这类兼容端点后可国内直连、人民币按量——配置要自己写（或用 CLI 脚本、第三方配置工具），这条路不受官方承诺，而且用不了 Codex Cloud 云沙箱。剩下四款里：想认真写代码选 ZCode 或 TraeWork，完全不想碰代码选码道CodeArts，要一个全能搭子选 WorkBuddy。
安全
贴进对话的内容都会被读取处理。ZCode 曾发生代码数据上传争议（官方已致歉、开源并整改）；处理未公开的作业、实验数据或论文素材时，优先选明确承诺不用于训练的工具，GLM 权重开源可自托管兜底。密钥、未公开答案不要直接贴进对话。

FAQ // 新生最常问

选之前先弄清 6 件事

Q1完全没基础，能直接用吗？−
能。WorkBuddy、TraeWork、ZCode 都对中文原生、国内直连，对话式上手；Codex 默认要代理 + 英文 + 美元，门槛最高——不过它读的是本地 config.toml，把 provider 指向 DeepSeek 这类兼容端点后可以不办 OpenAI 账号，代价是配置得自己写（或借助第三方工具）；CodeArts 偏企业流程，稍重。零基础先从轻量全能型（WorkBuddy）或免费编程型（ZCode/TraeWork）入手。
Q2哪个不用花钱就能用？+
免费权益不能直接等同：WorkBuddy 体验版每月 500 积分；ZCode 新用户试用 5 天，客户端显示 GLM-5.3 每日 300 万 Token、GLM-5.3-Flash 每日 500 万 Token；TraeWork 的积分、模型和活动权益以账号套餐为准；码道CodeArts体验版每月 500 积分。Codex 当前对 Free / Go 计划限时提供有限用量，具体限制以账号页面为准。积分和 Token 不能直接横向换算，长期使用前请核对官方计费规则。
Q3在国内都能直接打开吗？+
WorkBuddy、TraeWork、ZCode、CodeArts 都国内可用、无需代理；只有 Codex 的默认路径要科学上网。想在国内直连用 Codex，只能在本地配置里把 provider 指向 DeepSeek 这类兼容端点（非官方承诺的用法），代价是用不了 Codex Cloud 云沙箱；跑 GPT 模型则始终需要代理。
Q4主要想写代码，选哪个？+
想用国产开源大模型、跑长任务：ZCode（应用免费、模型按量，GLM 适配深）。想要 AI 工作台 + 手机随时派任务、三端同步：TraeWork。不太会写代码、想快速出成果：码道CodeArts。追最强模型且能接受折腾：Codex。
Q5我的代码/数据会被上传吗？+
贴进对话的内容会被读取处理。注意：ZCode 曾于 2026-09 发生代码数据上传争议，官方已致歉、开源并整改；对数据敏感的同学留意各工具的隐私设置，密钥/未公开答案不要直接贴。
Q6老师能直接拿去上课吗？+
可以。本站是讲义式排版，每章带「目标」提示块、要点、上手步骤与自检小测验，既适合学生自学，也方便老师当课件放映。价格为公开信息，课堂引用请标注更新日期并以官网为准。
