📚 想要一个覆盖学习+生活+办公的「万能搭子」+

推荐 WorkBuddy

  1. 1
    先用免费额度起步，不急着付费。
  2. 2
    从「写论文 / 做 PPT / 查资料 / 问生活办事」任一口子开始对话。
  3. 3
    常用流程可存成 Skill 一键复用，越用越顺手。
💻 主要做开发项目，手机也想随时派活+

推荐 TraeWork

  1. 1
    下载桌面端，并用同一账号登录网页 / 手机端，三端实时同步。
  2. 2
    按任务切 Work / Code / Design 三模式，云端 Agent 自动拆解。
  3. 3
    手机「按住说话」即可派活，回电脑看结果，通勤也能推进。
🧠 用国产大模型写代码、跑长任务（模型额度需另确认）+

推荐 ZCode

  1. 1
    应用可免费下载；新用户可试用 5 天。客户端显示 GLM-5.3 每日 300 万 Token、GLM-5.3-Flash 每日 500 万 Token。
  2. 2
    接模型：订阅 GLM Coding Plan，或自带 API Key 按量付费。
  3. 3
    用 1M 长上下文跑长程任务，或微信 / 飞书远程派单。
👥 团队 / 课程大作业，要规范与协作+

推荐 码道CodeArts

  1. 1
    开通 体验版（免费），额度不够再上月付档。
  2. 2
    用自然语言描述需求，直接搭出应用 / 工具雏形，降低开发门槛。
  3. 3
    用任务看板分派、让 AI Agent 自动执行，统一进度与评审。
🚀 追最前沿模型、愿意折腾配置+

推荐 Codex

  1. 1
    若走第三方模型，可在本地把 config.toml 的 provider 指向兼容端点（例如 DeepSeek）；这需要自行配置并按该服务商计费，不使用 OpenAI 账号额度。
  2. 2
    确实需要最强模型 + 云沙箱，再订阅 ChatGPT Plus / Pro（美元，且需科学上网）。
  3. 3
    用 Agent 跑复杂任务：多代理并行、自动写 PR、后台挂 Automation。
🤔 还是拿不准+

组合：WorkBuddy + ZCode / TraeWork

  1. 1
    日常学习 / 办公可先用 WorkBuddy 体验版，每月有 500 积分。
  2. 2
    写代码可比较 ZCode（5 天试用：GLM-5.3 每日 300 万、GLM-5.3-Flash 每日 500 万 Token）与 TraeWork（积分制，具体权益看账号套餐）。
  3. 3
    三款均可国内使用、支持中文；免费额度和模型费用不同，长期使用前先核对当前用量与计费规则。

③ 掌握度自查（不是考试，勾勾看）
